# Muofu AI Quota Lens 仓库开源化与重置安全 Implementation Plan

> **For agentic workers:** 按任务边界执行，行为修改必须先写失败测试并观察预期失败。不得回退其他代理或用户的修改。

**Goal:** 将现有 Firefox 扩展整理为可公开协作、可复现发布，并安全显示重置机会与最近已观测到期时间。

**Architecture:** 保持 MAIN world 被动观察、ISOLATED bridge 二次清洗和 `storage.local` 持久化三段式边界。reset credits 使用独立的最小状态模型；套餐与重置修复集中在既有 Core 纯函数中，UI 只消费清洗后的派生状态。

**Tech Stack:** Firefox Manifest V3、原生 JavaScript、Node.js test runner、Python `zipfile` 归档审计、Mozilla `web-ext`、GitHub Actions。

**执行状态：** Completed（2026-08-30）。本地仓库、功能、文档、可复现制品和 draft Release workflow 已验收；创建/公开 GitHub 仓库与 AMO 服务端提交仍属外部操作。
